**Tech:** JavaScript, WebGL, GLSL shaders

**Source:** [github.com/jlinie/CS405](https://github.com/jlinie/CS405) · [github.com/jlinie/project1-chatgpt-animate](https://github.com/jlinie/project1-chatgpt-animate)

## What It Is

A collection of computer graphics work built in JavaScript and WebGL:
transformations, lighting and shading models, texturing, and animation —
implemented at the shader level rather than through a high-level engine.
One of the projects also explored using ChatGPT as a coding assistant for
building WebGL animations, back when that was still a novel idea.

## What I Learned

Graphics programming is deceptively mathematical — matrices, projections,
and interpolation everywhere. Funnily enough, the same linear algebra that
rotates a 3D object is what powers the neural networks I work with today.
This course made those foundations concrete in the most visual way possible.
